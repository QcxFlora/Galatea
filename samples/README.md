`app/assets/characters/`、`web/assets/characters/` 里的立绘与头像来自《明日方舟》：

- 素材出处：客户端资源（经 [yuanyan3060/ArknightsGameResource](https://github.com/yuanyan3060/ArknightsGameResource) 镜像获取）
- **版权归鹰角网络（Hypergryph）所有**
- 仅用于本项目的**功能演示**（展示「角色方块 / 立绘方块」能力）
- 如果你要用作正式发布的作品，请替换为自己的原创素材
